# hanafubuki-agent

An AI coding and operations agent. It runs on its own, as a command-line and
terminal (TUI) application, or embedded as a Rust library in a host
application.

## Status

Under construction. The agent is being extracted from
[Hanafubuki](https://github.com/licyk/Hanafubuki), where it is developed today;
this repository holds only the workspace skeleton and its tooling so far.
