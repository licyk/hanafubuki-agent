会话有两种模式：**默认模式**下 Agent 直接完成任务；**计划模式**下它只读地探索代码，必要时向你提问，最后给出一份计划，而不修改任何东西。在动手之前想先看看 Agent 打算怎么做时，用计划模式。

## 进入和离开 [#switch]

在终端界面中输入 `/mode`，从列表中选择 `plan` 或 `default`。界面会显示 `• Mode set to plan`。回合进行中不能切换。`/status` 显示当前的模式。

`/new` 开始的新会话总是默认模式。`exec` 的会话也总是默认模式。

## 计划模式中有什么 [#tools]

- 只有只读的工具：读取文件、列出目录、搜索文本、网页搜索和抓取、只读的 MCP 工具、Skill 的列表和读取等。
- 可以向你提问（`request_user_input`），例如在几个方案中选择。
- 没有运行命令、修改文件、启用或停用 Skill 的工具，任何[权限模式](/docs/permissions)都不会改变这一点。

模型探索完成后，给出一份**提议的计划**，在对话中显示为 `• Proposed Plan` 及其内容。

## 执行计划 [#implement]

终端界面没有“执行这份计划”的按钮。要执行它：

1. 输入 `/mode`，切换回 `default`；
2. 发送一条消息，例如“按上面的计划实现”。

模型在同一个会话中，能看到之前的计划。

## 任务计划 [#task-plan]

默认模式下，模型可以用 `update_plan` 维护一个任务清单：最多 20 个步骤，每步是待办、进行中或已完成。终端界面中显示为 `• Updated Plan · 1/5 complete` 和带勾选框的步骤，较长的计划在展开之前只显示三个步骤（[阅读对话](/docs/terminal-interface#reading)）；`exec --json` 中是 `task_plan_updated` 事件。

任务计划只是模型给自己和你看的进度，不影响它能做什么。
