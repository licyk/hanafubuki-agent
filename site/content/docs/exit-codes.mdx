| 退出码 | 含义                                                                                                                                                                                                                   |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0      | 成功：回合完成，管理命令完成了要求的操作，终端界面正常退出，或者 `doctor` 没有 `FAIL`                                                                                                                                  |
| 1      | 失败：回合失败，Agent 在回合中停止，或者命令无法完成（没有 Provider、数据目录被占用、无法设置的键、不存在的配置档、Agent 无法启动、终端界面无法打开会话或使用终端）；`doctor` 有 `FAIL`                                |
| 2      | 命令行有误：未知的选项或命令、缺少参数、没有提示词、无效的 `--approve` 策略、不是数字的会话 ID、无效的 MCP 服务器 ID 或 `--env`、未设置的 `--api-key-env` 变量、`-c` 格式错误；以及在没有终端时运行终端界面或 `resume` |
| 3      | `exec`：模型提出的问题无人回答，回合被取消                                                                                                                                                                             |
| 130    | `exec`：回合被 Ctrl-C 中断                                                                                                                                                                                             |

失败时，错误信息以 `error:` 开头打印到标准错误。

## 在脚本中使用 [#scripts]

```sh
hanafubuki-agent exec "运行测试"
status=$?
if [ "$status" -eq 130 ]; then
  echo "被中断"
elif [ "$status" -ne 0 ]; then
  echo "失败（$status）"
fi
```

`exec` 的退出码与回合结果的对应关系见 [exec](/docs/exec#exit-codes)。
