The built-in `web` plugin includes the search implementation ported from [dsh-free-search](https://github.com/DDDMUC/dsh-free-search), v0.9.50 (`6ab5168`), in Rust. It needs no Node.js or DSH installation. Search results, fetched pages, cached excerpts and provider summaries are untrusted external data; their instructions are never authority for the Agent.

## Tools [#tools]

| Tool                            | Use                                                                                                                                                |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `web_search`, `advanced_search` | Search with a selected engine or the automatic fallback chain.                                                                                     |
| `multi_search`                  | Query a language pool concurrently, merge URLs and similar snippets, diversify domains and retain engine provenance.                               |
| `platform_search`               | GitHub, V2EX hot topics, Bilibili, Reddit, Hacker News (`hackernews`), Stack Overflow, Wikipedia, npm, YouTube, Vimeo, Juejin, Douban, Qiita or X. |
| `video_search`                  | Bing Videos and DuckDuckGo Videos, including automatic fallback.                                                                                   |
| `weather`                       | Open-Meteo current conditions and a 1–7 day forecast, with timezone and units.                                                                     |
| `domain_search`                 | Query a specialized source directly; choose the engine appropriate to the question.                                                                |
| `research`                      | Build a bounded evidence package, optionally rerank it and perform one gap-driven follow-up.                                                       |
| `cache_search`                  | Search research documents fetched within seven days, without network access.                                                                       |
| `fetch_web_page`                | Extract and paginate a public page; continue with the returned offset and content generation.                                                      |
| `free_search_test`              | Probe engines and inspect their errors, cooldowns and statistics. Explicit paid-engine probes consume credits.                                     |

`timeRange` accepts `day`, `week`, `month`, `year`, a duration such as `12h`, `3d`, `2w`, `3mo`, or an absolute `YYYY-MM-DD`. Engines with coarse time filters approximate durations; others receive a start date. Engine provenance means “retrieved by”, not independent corroboration.

The 39 concrete search engines are `duckduckgo` (upstream `ddg`), `ddg-lite`, `bing`, `searxng`, `degoog`, `anysearch`, `exa`, `tavily`, `keenable`, `firecrawl`, `parallel`, `perplexity`, `serpbase`, `serply`, `outcrawl`, `google`, `metaso`, `yandex`, `yuanbao`, `deepseek-official`, `deepseek-tools`, `you`, `baidu`, `kimi`, `aliyun`, `doubao`, `tinyfish`, `jina`, `zhihu_global`, `zhihu_site`, `agy`, `openai`, `gemini`, `claude`, `baidu-html`, `so360`, `sogou`, `wechat` and `toutiao`.

Metaso, Yandex, Yuanbao, OpenAI, Gemini and Claude require an explicit selection or host allowlist. The five SERP adapters (`baidu-html`, `so360`, `sogou`, `wechat`, `toutiao`) are opt-in. Optional credentials, account quotas, regional availability and page changes still apply. Fixture tests validate protocols, not live availability of every provider.

## Configuration [#configuration]

Open `/config pluginOptions.web`, or the `web` options form in `/plugins`. Options live under `[pluginOptions.web]` in `config.toml` and follow the normal configuration layers. For example:

```toml
webSearchProvider = "auto"

[pluginOptions.web]
provider = "multi"
language = "zh"
promptLanguage = "en"
zhPool = ["bing", "baidu", "aliyun", "anysearch"]
enPool = ["bing", "exa", "tavily"]
multiMaxEngines = 3
multiMinSources = 2
multiMaxResults = 20
blockedDomains = ["example.com"]
cacheEnabled = true
cacheTtlMinutes = 5
```

The older top-level `webSearchProvider` remains a host restriction: pinning it to `duckduckgo` or `searxng` overrides model-selected engines. Leave it `auto` to use the plugin's full engine catalog. The global network proxy, `searxngBaseUrl`, `webFetchUseJinaReader` and `webFetchResolveThroughProxy` still apply.

The Agent's secret setting fields are masked in forms; environment variables can keep API keys out of `config.toml`. DSH's credential center, plugin installer/updater, web UI and prompt page editor are replaced by the Agent's configuration, release, plugin and instruction facilities; DSH settings are not imported automatically.

Key rotation follows authentication, quota and rate-limit failures. Authentication rejection lasts for the current service instance; expiring cooldowns survive restart, keyed by SHA-256 identities without storing the raw key. Reset/retry hints are honored, with bounded delays; quota defaults to 45 minutes and monthly/region restrictions to 24 hours. SERP bot walls pause sibling SERP engines for ten minutes. Provider errors never include raw response bodies or credentials in tool diagnostics.

## Research and fetching [#research]

Research depth is 1–5. Each call has a 90-second deadline, at most 12 physical search requests including fallback/retries, at most twice the depth in fetched bodies, and at most twice the depth plus four fetch attempts. Candidate and window reranking share caps of 12 candidates and 48 windows; up to six windows per document fit a depth-dependent evidence budget. Code blocks and tables remain intact. Firecrawl and Crawl4AI additionally have per-research limits of three and two extraction calls.

The report keeps first-round evidence when a follow-up fills a comparison gap, records original fetch timestamps for cache hits, and distinguishes page bodies, provider summaries and snippets. Exact-title/URL clusters and semantic similarity are retrieval signals. Body folding requires very high similarity, matching available publication dates and compatible numeric claims. A second round requires a detected gap, successful evaluation and a negative sufficiency decision; it is not an unconditional extra search. Missing credentials, failed enrichment, exhausted budgets and partial results appear in the report.

Research documents and expiring engine cooldowns are stored as SQLite caches under `web-search/` in the Agent data directory. `RESEARCH_CACHE_DIR` can relocate the document cache. An unreadable database is left untouched and caching is disabled for that instance. Cache search returns excerpts, not a new fetch or a freshness guarantee.

Page extraction tries direct HTTP, optional local browser rendering, Exa/Firecrawl in the configured order, Crawl4AI, then the existing optional Jina Reader fallback. Unsupported or short pages may move to another tier. Direct HTTP validates every redirect and pins validated DNS addresses. Browser HTTP/CONNECT traffic uses the same public-target checks for redirects and subresources. Declared encodings, including GBK, are decoded before extraction; available page update dates remain metadata. All tiers retain byte/time bounds and the existing content-generation pagination contract.

## Optional local helpers [#local-helpers]

AGY needs an installed and signed-in Antigravity CLI (`AGY_BIN`, optional `AGY_MODEL`); X needs the signed-in Grok CLI (`GROK_BIN`). Browser rendering discovers Chrome/Chromium/Edge or uses `WEB_SEARCH_BROWSER`. Missing helpers leave HTTP/extraction fallbacks available.

Enable `localHelpersEnabled` explicitly. Calls that may use a local helper require an exact sandbox-escalation approval: a signed-in CLI runs outside the Agent sandbox and can access its account and local files. Helpers run in separate temporary directories, with bounded output/time and the Agent's process owner. Cancellation and dropping a call dispose the exact process receipt; unconfirmed termination retains ownership for shutdown. Browser rendering uses a fresh profile and does not disable the browser's own sandbox. Its forwarding layer currently requires the global proxy to be Disabled; System or explicit proxies skip the browser tier and continue with proxy-aware remote extraction.

An embedder can mount `web_plugin(Some(executor), Some(cache_directory))` with its Agent-owned executor, or pass `None` for HTTP-only operation. The web domain crate exposes a typed `LocalWebRunner` port and has no process dependency; the plugin owns the process adapter and approval boundary.
