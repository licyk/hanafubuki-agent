title: Exit codes
description: Every exit code of hanafubuki-agent, and what it means.

---

| Code | Means                                                                                                                                                                                                                                                                                                                                                  |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 0    | Success: the turn completed, a management command did what it was asked, the terminal interface was quit, or `doctor` found no `FAIL`                                                                                                                                                                                                                  |
| 1    | Failure: the turn failed, the Agent stopped during it, or the command could not finish (no Provider, the data directory in use, a key that cannot be set, a profile that does not exist, a role `roles show` does not find, the Agent could not start, the terminal interface could not open its session or use the terminal); `doctor` found a `FAIL` |
| 2    | The command line is wrong: an unknown flag or command, a missing argument, no prompt, an `--approve` that is not a policy, a session id that is not a number, an MCP server id or `--env` that is not valid, an `--api-key-env` variable that is not set, a malformed `-c`; or the terminal interface or `resume` without a terminal                   |
| 3    | `exec`: the model asked a question no one could answer, so the turn was cancelled                                                                                                                                                                                                                                                                      |
| 130  | `exec`: the turn was interrupted with Ctrl-C                                                                                                                                                                                                                                                                                                           |

On a failure, the message goes to standard error, starting with `error:`.

## In scripts [#scripts]

```sh
hanafubuki-agent exec "Run the tests"
status=$?
if [ "$status" -eq 130 ]; then
  echo "interrupted"
elif [ "$status" -ne 0 ]; then
  echo "failed ($status)"
fi
```

How `exec`'s exit code follows the turn's end is in [exec](/docs/exec#exit-codes).
